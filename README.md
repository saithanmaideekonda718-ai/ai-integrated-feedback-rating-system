# AI Integrated Feedback Rating System

A MERN stack based web application designed for collecting anonymous course feedback and ratings from students in an organized and efficient manner.

## Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* JavaScript
* HTML
* CSS

## Features

* Anonymous feedback submission
* Course rating system
* Responsive user interface
* API integration between frontend and backend
* Dynamic data handling
* Organized feedback management

## Purpose

The project was developed to simplify the process of collecting and managing student feedback while maintaining anonymity and improving usability.

## Project Structure

* Frontend built using React.js
* Backend APIs developed using Node.js and Express.js
* MongoDB used for database management
